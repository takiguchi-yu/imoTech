## なぜこのチケットでは今やらないか

- **Amazon アソシエイトは申請後 180 日以内に 3 件の適格販売が必要**で、未達だと申請が取り消される。
  閉鎖されたアカウントとアソシエイト ID は**復旧できない**（[ヘルプ](https://affiliate.amazon.co.jp/help/node/topic/G7MJTPEP9NC3YKMG)）。
  読者がいない段階で申請すると、ID を永久に失う。
- **AdSense は記事数・運用期間の公式要件が無い**代わりに、非承認理由が "not enough original, rich content that would be of value to users" という定性判断で返る。
  何本あれば通るという安全圏が作れないため、量ではなく密度で勝負するしかない。imo が積み上がってから申請する。

## 申し送り: 収益化を選んだことで使えなくなったソース

Q9 で収益化を前提にした結果、次の 2 つは規約上使えない。M1 の `ReactionSource` を抽象化してあるので、
方針が変わったときは実装を足すだけで戻せる。

- **はてなブックマークの API / oEmbed**: Developer Center 利用規約 第4条1項が「宣伝や商用を目的とした内容。ただし当社が特別に許諾を行った場合を除きます」を禁止。
  **リンクを置くこと自体は規約上まったく問題ない**（はてな利用規約にリンクを禁じる条項は存在せず、公式ヘルプが「そのリンクを公開することも自由である」と明文化している）。
  ただし OGP プレビューは `og:description` にブックマークコメント本文が逐語で入るため、実質的な転載になる。テキストリンクのみに留めている。
- **Reddit**: Data API Terms が商用利用に別途の書面合意を要求し、Responsible Builder Policy が
  "You must not sell, license, share, or otherwise commercialize Reddit data without express written approval" と定める。
