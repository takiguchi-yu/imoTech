## 元記事の要旨

- Claude Code 2.1.277で共通指示ファイル「AGENTS.md」のサポートが導入されたものの、テレメトリを無効化している環境ではファイルが読み込まれない現象が発生しました。
- 調査の結果、この機能は内部プラグインとして実装され、有効化の判定がリモートのフィーチャーフラグに依存しているため、通信を遮断すると無効化されることが判明しました。
- 読み込みがスキップされても警告は一切出力されず、第三者ゲートウェイや特定クラウド経由で利用する企業など、不要な通信を制限している環境に広く影響していました。
- 検証者は回避策として「CLAUDE.md」からインポートする方法を提示しつつ、ローカルファイルの読み込みが外部通信に依存する仕様の不自然さを指摘しました。

### 大規模ソフトウェアにおけるキルスイッチの必要性
